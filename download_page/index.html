Everything from the mind map, in one app

Home, add note, note detail, search, settings and the data layer are implemented exactly as planned.

🏠

Home page

Header and logo, search bar, pinned notes, recent notes, all notes and a floating add button.

📝

Add & edit notes

Title, content, pin toggle, save and cancel — with validation so a note cannot be saved without a title.

📌

Note detail

View title and content, edit, delete with confirmation, and pin or unpin straight from the page.

🔎

Search

Keyword search over title, content, or both. Parameterised SQL, friendly empty results, one-tap clear.

🌗

Theme memory

Light, dark or follow the system. The choice is persisted and restored before the first frame.

💾

Export JSON

Write every note to a timestamped JSON snapshot in the app documents folder, then copy the path.

Data storage

  • SQLitenotes table with id, title, body, pinned, createdAt and updatedAt — CRUD, pinning and search run in the database.
  • Prefstheme_mode in shared_preferences, read once at startup with a safe default.
  • Filehans_notes_<timestamp>.json snapshot written to the application documents directory.

Why this mix

  • 01Notes are many records, not one blob — so a row per note in SQLite.
  • 02Search and pinned-first ordering need conditional queries — WHERE … LIKE ?, ORDER BY.
  • 03The theme is a single small value that must survive a restart — exactly what shared_preferences is for.

Install on Android

  1. Scan the QR code or tap Download APK.
  2. Open the downloaded file from your notifications.
  3. Allow installs from this source when Android asks.
  4. Launch Hans Smart Local Notes — no sign-in required.

Install on Windows

  1. Download HansSmartLocalNotes-Windows.zip.
  2. Right-click the zip → Extract all.
  3. Run hans_smart_local_notes.exe from the extracted folder.
  4. Keep the whole folder together — the exe needs its data files.
